# Spring Bootcamp

This repository contains all tasks, projects, and practice work completed during the **Java Web Developer Bootcamp**.  
The bootcamp focuses on building **enterprise-scale backend applications** using **Java and the Spring ecosystem**.

---

## Bootcamp Overview

This bootcamp provided hands-on training in Java backend development, with a strong focus on real-world application development using the Spring framework.

Throughout the training, I worked on implementing backend concepts, building RESTful APIs, integrating databases, and applying best practices in software design through practical tasks and projects.
